FONTLOG for the Soharab font

This file provides detailed information on the Soharab Font Software.
This information should be distributed along with the Soharab fonts
and any derivative works.

Basic Font Information

Soharab is an authentic, expressive handwriting variable typeface designed
by Sohrab Zia. Captured directly from physical pen-on-paper handwriting
and digitized into continuous OpenType variation axes for pen pressure weight
(100 to 900) and slant (-12 to 0 degrees).

ChangeLog

26 November 2026 (Sohrab Zia) Soharab Version 1.0.2
- Full Latin Core glyphset expansion: 185 mapped characters (186 glyphs).
- Added complete Western & Central European accented characters (70 glyphs: À–ÿ, Œ, œ, Š, š, Ž, ž, etc.).
- Added currency symbols ($, €, £, ¥), math operators (+, =, %, ±, ×, ÷), and typography marks (@, &, ©, ®, ™, •, …, dashes).

21 November 2026 (Sohrab Zia) Soharab Version 1.0.1
- Google Fonts packaging, OFL 1.1 licensing, and METADATA.pb specification.
- Direct jsDelivr CDN and npm package release.
- 75 glyphs supporting uppercase, lowercase, numbers, and basic punctuation.
