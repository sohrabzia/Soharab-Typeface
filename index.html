Frequently Asked Questions

Everything you need to know about licensing, variable axes, web embedding, and platform installation.

01 What is Soharab font and what makes it unique?

Soharab is an authentic, free-style handwriting variable typeface designed by Sohrab Zia. Captured directly from physical pen-on-paper handwriting and vector-digitized, it preserves spontaneous human stroke variation and warmth. Unlike static fonts, Soharab features a continuous two-axis variable architecture offering dynamic weight interpolation (from fine nib to heavy marker) and natural cursive slant tilt.

02 Is Soharab free for commercial use?
100% Free for Commercial & Personal Use

Yes. You can freely embed Soharab in commercial websites, mobile apps, SaaS interfaces, printed products, logos, branding packages, merchandise, books, and marketing video content with zero royalty payments, attribution requirements, or recurring license fees.

03 What variation axes are included in Soharab-VF.ttf?

Soharab-VF incorporates two continuous variation axes:

Weight (wght: 100–900)
From ultralight fine nib pen (100) to heavy marker stroke (900).
Slant (slnt: -12°–0°)
From casual cursive forward tilt (-12°) to upright hand print (0°).

It also provides 8 pre-configured named instances: Thin, Light, Regular, Medium, Bold, Black, Casual Slant, and Expressive Script.

04 How do I use Soharab in web design with CSS?

Declare the font via standard CSS @font-face and control axes with font-variation-settings:

@font-face {
  font-family: 'Soharab';
  src: url('./Soharab-VF.ttf') format('truetype');
  font-weight: 100 900;
  font-style: oblique 0deg 12deg;
  font-display: swap;
}

.handwritten {
  font-family: 'Soharab', cursive, sans-serif;
  font-variation-settings: 'wght' 600, 'slnt' -6;
}
